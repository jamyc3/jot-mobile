# Security Policy

## Reporting a vulnerability

Please report vulnerabilities privately via GitHub's private vulnerability
reporting: go to the **Security** tab of this repository and click
**Report a vulnerability**. Do not open a public issue for security
problems.

You can expect an acknowledgment within 7 days. Please include steps to
reproduce and the app version affected.

## Scope

Jot iOS processes speech on-device; cloud AI features are strictly opt-in.
Reports about audio, transcripts, or keyboard input leaving the device
outside explicitly opt-in paths are treated as highest severity — the
keyboard extension especially.

## Supported versions

Only the latest App Store release receives security fixes.
